
# SV Injector UX Polish N5.43.4

This iteration focuses on final visual polish of the SV Injector workspace shell.

- Increased toolbar height and padding so hover shadows and button pop-up motion are not clipped.
- Removed WPF focus dotted visuals from ribbon buttons.
- Reworked ribbon buttons as custom templated surfaces with tactile hover and pressed transforms.
- Start button uses a blue action gradient; Stop uses a red action gradient.
- Card header gradient is now bright/exciting on the left and deep readable blue on the right.
- Card elevation is slightly stronger for a more premium instrument-workspace depth.
- Scrollbars are slim rounded thumbs with brighter hover/drag states.

No injection logic changes are included in this patch.
