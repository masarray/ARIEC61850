# ARIEC61850 GitHub Pages

Static project website for the ARIEC61850 IEC 61850 engineering toolkit.

The deployment workflow publishes this folder as the website root and copies the public Markdown documentation into `/docs` for direct file access. User-facing documentation links point to the rendered GitHub repository pages, while the website provides the project overview and a dedicated Smart Control page.

Public pages:

- `index.html` — product overview and engineering positioning.
- `smart-control.html` — IEC 61850 Direct/SBO control architecture and operator workflow.
- `sitemap.xml` and `robots.txt` — crawler discovery.
- `site.webmanifest` — application/site metadata.
