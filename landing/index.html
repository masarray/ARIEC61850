Protocol-grade IEC 61850 tools without a black-box runtime stack.

ARIEC61850 provides MMS discovery, report planning, GOOSE, Sampled Values, SCL, PCAP, diagnostics, CLI automation, and a Windows WPF SV publisher for lab and FAT/SAT engineering work.

Toolkit

Built for engineers who need evidence, not guesswork.

MMS model discovery

Build a live IED directory, resolve Functional Constraints, inspect datasets, and read values without forcing users to guess MMS path details.

Process-bus tooling

Create, inspect, and replay GOOSE/SV frames with SCL-backed profiles and PCAP helpers for repeatable lab validation.

Desktop SV publisher

Use the WPF workspace for Sampled Values publishing experiments, waveform setup, and Windows lab adapter workflows.

Reporting

RCB/DataSet selection belongs in a guided setup flow.

ARIEC61850 treats reporting as a guarded state machine: discover first, plan safely, enable explicitly, monitor evidence, then disable and cleanup.

  1. Connect IED
  2. Discover model, datasets, and RCBs
  3. Validate report readiness
  4. Enable, GI, monitor, export evidence

Release

Windows WPF single-file package.

The release workflow publishes the SV Publisher as a self-contained Windows x64 EXE and also creates a small ZIP with license and quick-start docs.
