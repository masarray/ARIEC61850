IEC 61850 client control

Smart IED control without exposing raw MMS writes to the operator.

The ARIEC61850 Smart Control Tester turns a live control Data Object such as LD0/CSWI1.Pos into a guarded OPEN/CLOSE workflow. The native engine discovers the IED's control model, exact MMS value type, status reference, and required sequence.

Operator guide Engine architecture

Operator experience

Process intent first.

The user selects CSWI.Pos, verifies the current OPEN/CLOSED state, confirms the test circuit is safe, and presses OPEN or CLOSE. Advanced options remain available without dominating the normal workflow.

  • Live control-object and status discovery
  • Automatic Direct or SBO selection
  • Interlock and synchrocheck request bits
  • Test mode, originator, and Orig ID
  • Command timeout, Cancel, and association cleanup
  • Request, response, termination, and status evidence

Protocol sequencing

All four IEC 61850 control models are represented explicitly.

Control modelSequenceSuccess boundary
Direct normalOperConfirmed MMS acceptance
SBO normalSBO → OperConfirmed MMS acceptance
Direct enhancedOper → CommandTerminationPositive termination
SBO enhancedSBOw → Oper → CommandTerminationPositive termination

The stack keeps ctlVal, origin, ctlNum, timestamp T, Test, and Check values consistent across the sequence. Generic application writes to control service members are blocked so product code uses the typed control session.

Failure diagnosis

Accepted is not the same as completed.

Enhanced-security commands remain pending until the matching CommandTermination arrives. Rejection, timeout, association loss, caller cancellation, negative termination, and process feedback mismatch remain separate outcomes.
